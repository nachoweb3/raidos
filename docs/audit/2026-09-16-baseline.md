Escaneo acotado por patrones de claves privadas/tokens conocidos no encontró coincidencias fuera de dependencias, builds, outputs o .env. Esto no es un análisis de todo el historial ni una garantía de ausencia de secretos. No se imprimieron valores de .env. Falta .env.example para app. Docker excluye datos y secretos; Fly monta `/data`. Ninguna infraestructura externa se modificó en esta auditoría.

## Decisiones de implementación

1. Cerrar bypass financiero y corregir datos engañosos con regresiones.
2. Catálogo SQL aditivo, cursor keyset sobre filas reales, trabajos persistentes, importación exacta por contrato. Los proveedores de páginas conservan checkpoints de página; no se inventa cursor upstream.
3. Filtros por columna sobre catálogo, estado en URL y panel adaptable; mantener módulos y contratos existentes.
4. Conservar Lightweight Charts existente y ampliar solo con indicadores calculables/licencia compatible. No hay evidencia de licencia de Charting Library propietaria.
5. Dinero real, despliegue y migraciones externas siguen requiriendo autorización.

Referencias contrastadas: [DEX Screener](https://docs.dexscreener.com/api/reference), [GeckoTerminal](https://apiguide.geckoterminal.com/), [Lightweight Charts 4.1](https://tradingview.github.io/lightweight-charts/docs/4.1), [Jupiter quote](https://developers.jup.ag/docs/api-reference/swap/v1/quote).
