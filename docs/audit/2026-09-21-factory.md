# Launch issuance hardening

Published API: deployment-01M3175V4YWVY62PGHXT3XQBD7. Web: cbe209f / 20260921-1.

Fixed reversed mint/owner ATA derivation; bind every execution to canonical prepared plan; reject altered destinations before sending. Match URL launch ID. Limit batches to four holders and verify actual serialized transaction sizes with 18 allocations. Create mint without freeze authority.

Persist a compare-and-set execution lock in SQLite. Persist signed transaction bytes and locally derived signature before network submission, so an ambiguous send can be investigated without issuing again. Require RPC signature match and explicit successful confirmation. Preserve journal on API errors. Block repeat execution, replanning, curve trades and claim changes while executing or requiring recovery. Validate ledger again after acquiring lock.

Validation: 299 app tests, TypeScript and build pass. Tests include recipient tampering, failed confirmation, ambiguous send, concurrent execution, claim changes, actual SQLite compare-and-set and 1232-byte packet size. These tests use offline Solana stubs; no funded on-chain execution was performed.

Limitations: no automatic recovery/reconciliation yet, no funded or configured factory signer in production, no real bonding curve or external liquidity integration. Existing partial executions require operator review rather than automatic remint. The disabled operator AMM remains disabled. No mainnet readiness claim.

UI adds public read-only launch detail, issuance state and real-mint navigation into the standard market terminal. Public production launch list was empty during this release; no test launches were inserted into production.
