# RaidOS Onboarding Playbook (48h launch)

## 0–2h: Collect assets
- Telegram group link
- Bot token or we create it together
- Token contract + symbol
- Official FAQ/docs/pinned messages

## 2–6h: Deploy core
- Install RaidOS
- Connect token to /volume
- Load official KB via /learn
- Set alert thresholds

## 6–24h: Activate engagement
- /setup in group
- Turn on quests + badges
- Schedule first raid with mods
- Enable content engine

## 24–48h: Tune and report
- Review first /brain and /content stats
- Adjust tone, thresholds, and cadence
- Ship admin walkthrough
- Set weekly reporting rhythm

## Success metric (Week 1)
- /ask answers the top 5 recurring questions
- First raid completed with tracked actions
- At least 3 content posts published via /content
